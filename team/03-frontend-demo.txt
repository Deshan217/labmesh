PRODUCT AND DEMO
A community workshop needs one instructor-selected starter kit on many laptops sharing limited internet. LabMesh is a Manifest V3 Chrome extension with a full-page room view. Clicking the toolbar icon opens the room tab. Keep that tab open during transfer. A selects one local file, B and C join the room explicitly, and all three exchange verified chunks over reliable ordered WebRTC data channels. A separate FastAPI WebSocket service introduces peers and relays negotiation messages only. Run it on B or a fourth device so disconnecting A does not take the coordinator away. Venue LAN or team hotspot with client-to-client traffic permitted. No account, TURN service, cloud storage, browsing-history access or third-party CDN is required for this demo. Make no claim about every network or real classrooms until tested.

SHARED INTERFACES (plain ES modules unless specified)
• Load extension/ as an unpacked extension. extension/app.js is the composition root. transport.js exports async connect({endpoint,roomCode,displayName,action,onEvent}) -> transport. action is "create" or "join". Create receives roomCode="" and the service generates the code. transport exposes {selfId,roomCode,hostId,send(peerId,payload),close()}. send returns a Promise, accepts a string or ArrayBuffer and handles queueing/backpressure in order per peer. onEvent receives {type:"open",peerId,name}, {type:"close",peerId}, {type:"data",peerId,payload}, or {type:"error",message}. Queue events in app.js until the engine exists, then drain in order. Peer IDs are strings. Peer data starts only after a channel opens.
• engine.js exports createEngine({selfId,hostId,send,onState}) -> {onPeer(event),share(file,{mode}),pause(),resume(),getVerifiedBlob(),close()}. share is async, used by A, and mode is "normal" or "demo". onPeer consumes open/close/data. pause/resume control local requesting. getVerifiedBlob returns Blob or null. close releases memory, timers and listeners. One file per room, 1 byte to 8 MiB. Keep receivers in memory for the session; page refresh starts over.
• ui.js exports mount(root,actions) -> {render(state),destroy()}. actions are create({endpoint,name}), join({endpoint,roomCode,name}), share(file,{mode}), pause(), resume(), save(), leave(). root is a DOM node. app.js supplies all actions. Initial render and all updates receive full snapshots, not incremental patches.
• Complete UI state is {session,selfId,hostId,roomCode,error,transfer}. session = "idle"|"connecting"|"inRoom"; error is a human-readable string or null. transfer (from engine) = {phase,mode,fileName,fileSize,chunkCount,peers,localVerifiedBytes,verified,readyToDisconnect,paused,detail}. phase = "empty"|"seeding"|"exchanging"|"waiting"|"checking"|"complete"|"error"; mode = "normal"|"demo"; peers = [{id,name,online,have:[zeroBasedChunkIndexes]}], including self. Missing file uses empty name and zeros; detail is a short string. Receiver progress is locally verified bytes divided by file size. readyToDisconnect is a derived real condition described below, never a timer.
